# Wikigender: How Biographies Frame Scientists

This is a computational social science project about English Wikipedia biographies of scientists.

We compare a balanced sample of women and men scientists across five STEM fields: biology, chemistry, computer science, mathematics, and physics. The project looks at article length, gender-associated words and bigrams, science/family word clusters, word co-occurrence networks, and permutation-tested differences.

The public website presents the main story for a non-technical reader. The explainer notebook contains the data collection, preprocessing, analysis, visualizations, network construction, and statistical testing.
